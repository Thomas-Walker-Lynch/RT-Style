Scope

Harmony's files and directories are named by the rules in RT-Style's naming.html: the separator ladder, demotion where a language reads the name, proper nouns, namespaces, and directories named for a property of their files. This document adds only the names Harmony's layout and build give meaning to.

Directory

Each directory of the skeleton names a property every file in it has:

  • who works with the files, by role: administrator, developer, tester, consumer;
  • how the files came to be: authored files are written by people or by AI, and made files are products of tools;
  • what the files are for: tool, document, experiment, project-dependency;
  • how long they last: scratchpad holds work that the tools make again and that is not kept.

Namespace source directory

Each directory in developer/authored holds the source of one namespace, and is named <namespace>.<build tool>. The suffix names the build component that builds it, in developer/tool/build_component: copy stages its files as they are, and make runs Harmony.mk on them. The part before the suffix is the namespace's name. The build passes it to the compiler, which puts it in macro names, so it is written in its demoted form:

  • Account_Tree.copy holds the namespace of the project Account-Tree.
  • Man_In_Grey__Gate.make holds the namespace Man-In-Grey_Gate.

The build stages each namespace into scratchpad/made/<namespace>, and promotion copies it to consumer/<namespace>. A directory without a suffix, such as deprecated, is not built.

Property suffix

The build reads these suffixes on file names:

  • .lib.c : a library module, compiled to an object file and added to the project's archive. Its base name is the module's name, and the build defines <namespace>·<module> when compiling it, so the base name is written demoted.
  • .CLI.c : a program, compiled and linked into a stand-alone executable of the same base name.
  • .kmod.c : the source of a kernel module.
  • .mk : makefile text that is included, never run. In a namespace source directory, Harmony.mk reads it after its own defaults and the project's developer/tool/build_component/project.mk, so it has the last say; the build stages it with the namespace's library.
  • .init : in shared/project-dependency, a bash fragment that a role's setup sources, to put a dependency on the paths.
